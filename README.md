# 素材库

本地优先的 Obsidian 素材面板。本地功能无需联网；云端用于浏览和选取素材，插入笔记前保存原图到本地。无需构建或其他插件。

## 使用

1. 在「设置 → 第三方插件」启用「素材库」，必要时重启 Obsidian 刷新列表。
2. 点击左侧图片图标，或执行「素材库：打开素材库」命令。
3. 点击「导入素材」或从系统文件管理器拖入文件。原文件不会被移动；导入副本保存在库内。同名素材带唯一后缀，不覆盖旧文件。
4. 「新建分类」创建子文件夹；选中分类后，新素材会导入该分类。选择额外目录或「整个笔记库」时，导入仍保存到主素材库目录，状态栏会标明目标。
5. 搜索名称或路径，按类型和分类筛选；单击多选、双击预览、右键复制路径或嵌入链接。分类包含其子目录。
6. 先打开目标笔记，再打开素材库，选择素材并点击「插入所选」。素材以嵌入链接插入最后活动的笔记光标处；目标笔记必须仍然打开。
7. 在插件设置页或面板的「设置」按钮中调整主目录、额外目录、缩略图尺寸、名称显隐和排序。修改后点击保存；改路径不会移动已有素材。

## 写笔记时插入图片（1.6.0，本地优先）

- 在目标笔记里打开命令面板，执行「素材库：插入素材库图片」，点击缩略图直接插入光标位置。也可从笔记编辑区的右键菜单进入。选择器可搜索图片、切换查看整个笔记库；使用本地文件的正常嵌入链接，不生成副本。
- 执行「素材库：插入云端图片」打开云端页，点击「下载到本地并插入」。原图先保存到当前素材库目录下的 `云端导入/`，默认是 `素材库/云端导入/`，再以普通本地图片链接插入目标笔记。保留原格式和原始字节，不用 WebP 缩略图替代原图。
- 同一连接、路径与文件版本复用已有本地副本；不同来源的同名图片分别保存，不覆盖旧文件。同图并发下载只创建一份。已下载文件可离线重复插入，云端预览也优先读取本地副本。
- 新插入的笔记不依赖网盘授权、临时签名或本插件；本地图片存在时，离线或关闭插件仍可显示。下载副本作为普通本地素材使用，不自动同步远端修改。
- 下载完成后会确认目标笔记未关闭或切换；目标变化时只保存本地图片，不误插入其他笔记。下载失败不会插入失效链接。
- 旧版 `material-image` 引用保留兼容显示，不批量修改已有笔记。其显示仍需对应连接配置；有本地副本时优先使用本地，否则按原有授权读取。新插入不再生成云端引用代码块。

默认主目录是 `素材库`，额外展示 `从夯到拉/素材库`，兼容已有分级榜素材。可通过「整个笔记库」浏览其他已有素材。若从夯到拉使用自定义素材路径，请将其添加到额外目录。素材库与分级榜相互独立，选择已有文件不会创建副本。

支持图片 PNG/JPG/JPEG/GIF/WebP/AVIF/BMP/SVG，视频 MP4/WebM/MOV/MKV，音频 MP3/WAV/OGG/M4A/FLAC，以及 PDF。音视频播放能力取决于 Obsidian 所在设备的解码器，PDF 通过 Obsidian 打开。图片保持原文件，不进行压缩或重采样。网格使用懒加载与分批显示。

本插件不自动删除文件。素材目录可按普通库内文件夹同步和备份。

## 云端素材（1.3.0）

通过面板顶部「云端素材」、命令「素材库：浏览云端素材」进入。在「设置 → 云端连接 → 管理连接」添加连接，填写后可「测试连接」。当前仅支持 **WebDAV、S3**，每种类型都支持多个连接。

云端素材在主工作区的独立标签页中打开，可以像本地素材库一样全页浏览、拖动分栏和切换标签。再次点击入口会返回已有云端标签页，保留当前浏览状态，不会重复打开。页面右上方「本地素材」可返回本地素材库；连接设置和单张大图预览仍使用弹窗。

- **WebDAV**：填写完整素材目录地址及服务账号密码。插件通过 PROPFIND / GET 只读浏览该目录及子目录。
- **S3 / S3 兼容存储**：填写 Endpoint、Bucket、Region、Access Key 和 Secret Key；支持目录 Prefix、Path-style / Bucket 子域名及临时会话令牌。需要对应目录的 ListBucket 和 GetObject 权限。

使用「＋ 添加 WebDAV / S3」继续添加其他账号、服务或 Bucket。每个连接独立命名、保存、编辑和移除，不会互相覆盖。名称重复时自动追加序号；「复制为新连接」可复用已有配置，副本需点击保存，凭据默认仅留在内存。云端连接选择器按类型分组，保存或移除后自动更新。

云端支持目录导航、搜索当前已加载的目录、自动预览和大图查看。S3 可加载下一页；WebDAV 由服务一次返回当前目录。浏览时不会递归下载整盘；点击「下载到本地并插入」才持久保存所选原图。不会上传、删除或同步云端文件，也不会将临时外链写入笔记。

### 减少原图等待（1.5.0）

1. **服务端缩略图规则**：编辑每个连接，可填写「服务端缩略图规则」。留空时沿用原图；填写后列表优先读取该地址，而不读取原图。服务本身必须提供对应接口或已生成的缩略图，插件不会自动部署服务。失败时会回退读取原图。
   - URL 示例：`https://你的缩略图服务/thumb?path={path}&width={width}`。
   - 同服务相对地址示例：`/thumbs/{pathSegments}.webp`。
   - S3 私有同桶对象示例：`s3://thumbs/{path}.webp`，插件会为缩略图对象生成签名，不要求桶公开。
   - `{path}` 为 WebDAV 素材目录下的相对路径，或 S3 完整对象 Key；URL 模式会整体编码，适合查询参数。`{pathSegments}` 保留目录层级、逐段编码，适合 URL 路径。另支持 `{name}`、`{bucket}`、`{width}`、`{height}`。S3 同桶模式直接生成对象 Key，不进行 URL 占位符编码。
   - WebDAV 缩略图只有与原服务同源时才带原账号授权；跨域缩略图服务不接收账号密码，需要提供可读取地址。模板修改会使用新的缩略图缓存，原图缓存仍可复用。
2. **大图渐进显示**：打开大图时，已有缓存缩略图会立即显示；原图完成读取与解码后再替换，期间保持小图可见。
3. **原图优先**：查看大图或渲染笔记内云端原图时，暂停尚未开始的后台预览队列；原图请求完成后恢复。已在传输的请求不强制中断。原图与缩略图各自缓存，重复原图请求仍合并。

### 空间、流量与凭据

- 自动预览默认开启，进入目录后直接加载可见图片，滚动时继续加载新出现的图片，无需逐张点击；可临时取消勾选关闭自动预览。默认最多 4 个并发加载，可在设置中调整到 1～8。WebDAV / S3 首次预览仍可能需要读取原图，会消耗网络流量与服务请求次数。
- 已读取的原图和缩略图在内存中共享缓存，最多 64 MB，按最近使用顺序淘汰，5 分钟后失效。同图的并发请求合并；搜索、重绘、重开窗口或查看大图时优先复用，不会重复下载已缓存的原图。不同连接、账号凭据和文件版本分别缓存，WebDAV 使用 ETag / 最后修改时间，S3 使用 ETag / LastModified 区分版本。服务不提供版本信息时由缓存有效期控制。
- 「轻量 WebP 预览」默认开启，静态图片在内存生成缩略图，默认最长边 480 px、质量 78%，保持比例和透明度，不放大。尺寸较小但文件超过 32 KB 的静态图片也会尝试转换；转换结果更大、编码不受支持或失败时沿用原格式。GIF、APNG、动画 WebP、SVG 和 AVIF 保留原样，避免丢失动画或矢量细节。
- 可在设置中开关轻量预览、调整最长边（200～1000 px）和质量（50～95%）。不同参数的缩略图分别缓存，调整参数时优先复用已缓存原图；查看大图始终使用原图。不会修改或重新上传云端文件，不写入笔记库。
- 这种转换主要降低预览解码和重复查看开销。首次读取速度仍取决于网络和 WebDAV 服务，客户端转 WebP 不能减少首次原图传输量；要加速首次传输，需要服务端提供缩略图。
- 单纯浏览不写入笔记库，明确插入时保存原图到本地。关闭窗口会释放显示用临时地址，内存缓存保留供复用。「清除预览缓存」只清理内存，不删除已下载的本地图片。单图限制 30 MB（响应返回后检查，并非流量硬上限），当前目录显示的缩略图累计限制 64 MB，最多显示 100 项。
- 密码和 Secret Key 默认仅保留在本次运行的内存里。可主动开启「重启后保留凭据」，开启后凭据明文写入插件 data.json，可能随笔记库同步，请勿分享。
- OpenList 独立选项已移除。旧配置仍保留在配置文件中，但不显示、不使用、不发起连接。已有 WebDAV、S3 连接及多连接功能继续可用。

## 开发验证

修改云端源码后执行 `node bundle-cloud.cjs` 更新入口，再执行 `node --check main.js`。`node test-cloud.cjs` 使用本机无界面 Chrome 和模拟响应运行离线集成测试，验证 XML、目录边界、分页、凭据保存选项、预览释放和 S3 签名；不连接真实网盘、不使用真实凭据。可用环境变量 `ML_TEST_BROWSER` 指定浏览器可执行文件。真实账号的权限、网关驱动和网络仍需在插件界面测试。
